# Remix of Remix of Remix of Heat Onn Forge

Build a Premium Industrial Website Homepage for HEAT ONN

Create a modern, premium, responsive homepage for HEAT ONN, an industrial equipment and heating solutions company.

The website should look like a professional engineering/manufacturing company, not a generic small-business website and not a SaaS landing page.

Use the provided previous HeatOnn website and DryTray India website only as visual/structural references. Do NOT copy their design, text, branding, layout, or code.

Reference websites:

Previous HeatOnn website: https://heatonn-new.onrender.com

Visual/structural reference: https://www.drytrayindia.com/

The new website must have its own identity.

1. Overall Design Direction

Design language:

Premium Industrial + Modern Engineering + Clean Corporate

The visual identity should communicate:

Engineering

Precision

Heat

Manufacturing

Reliability

Industrial technology

Professionalism

Product quality

Avoid making the website look:

Like a generic WordPress business template

Like an e-commerce store

Like a cheap industrial supplier website

Overly colorful

Overly futuristic

Excessively glassmorphic

Like a SaaS dashboard

The website should feel comparable to a professionally designed modern industrial manufacturer website.

Take inspiration from the cleanliness and polish of modern brands such as Linear, Apple, Vercel, and premium engineering companies, but adapt the design specifically for industrial machinery.

2. Color System

Use a restrained industrial color palette.

Primary:

Near Black: #111111

Dark Charcoal: #181818

Warm White: #F7F7F5

Pure White: #FFFFFF

Heat Orange: #E85D04

Secondary neutrals:

#6B6B6B

#A0A0A0

#E5E5E5

Orange must be an accent, not the dominant color.

Use the orange for:

Primary CTA

Hover states

Small visual highlights

Important numbers

Section indicators

Small lines/borders

Selected navigation states

Do not make the entire website orange.

3. Typography

Use a modern professional sans-serif typeface.

Preferred:

Inter

Manrope

Plus Jakarta Sans

Use:

Large bold typography for major headings

Medium weight for section headings

Regular weight for descriptions

Small uppercase labels for section categories

Typography should feel technical and premium.

Example heading style:

ENGINEERED FOR
BETTER PERFORMANCE.

Large, bold, compact line-height.

19. RESPONSIVE DESIGN

The website must be fully responsive.

Desktop:
1440px+
Primary design target.

Laptop:
1024–1439px.

Tablet:
768–1023px.

Mobile:
320–767px.

Mobile requirements:

Hamburger navigation

Hero becomes single-column

Image moves below text

Product grids become 1-column or 2-column depending on width

Application cards become stacked

CTA buttons become full-width where appropriate

Typography scales smoothly

No horizontal scrolling

Touch-friendly buttons

Proper spacing

Do not simply shrink the desktop design.

Create a proper mobile composition.
