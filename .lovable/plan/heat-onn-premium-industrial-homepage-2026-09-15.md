# HEAT ONN Premium Industrial Homepage

## Goal
Build a polished, responsive homepage that presents HEAT ONN as an industrial engineering and equipment company, with clear product discovery and quote-generation paths.

## What I’ll build
- A sticky desktop and animated mobile navigation with working links to Home, About, Products, Applications, Contact, and quote actions.
- A cinematic split hero using original industrial machine imagery, strong technical typography, and the supplied headline and supporting copy.
- Credibility strip, engineering introduction, configurable solution categories, six configurable featured products, verified applications, engineering benefits, process flow, full-width industrial image break, quote callout, and footer.
- Placeholder About, Products, Applications, Contact, and product-detail routes so every link works immediately.
- Centralized product, category, application, and navigation data for easy future catalogue updates.
- Subtle scroll reveals, image zooms, navigation transitions, and motion-reduction support.
- Unique homepage metadata, semantic headings, descriptive image text, and route-specific metadata for linked pages.

## Visual system
- Near-black and charcoal surfaces, warm white backgrounds, neutral greys, and restrained heat-orange accents.
- Manrope for a technical, premium character with compact uppercase display headings and clear body copy.
- Large, consistently framed product imagery; minimal borders and shadows; crisp 4–8px radii.
- Responsive compositions designed independently for desktop, tablet, and mobile without horizontal overflow.

## Content and imagery
- Use verified HEAT ONN catalogue names, applications, founding information, and contact details only where public sources support them.
- Any unverified specification stays as clearly editable neutral copy rather than a fabricated claim.
- Create cohesive original stainless-steel equipment and industrial-process imagery where suitable source photography is unavailable.

## Technical details
- TanStack Start routes with React, TypeScript, Tailwind CSS v4, existing Button/Sheet components, and Lucide icons.
- Reusable homepage sections and card components, backed by typed data objects.
- Semantic design tokens in the global stylesheet; no ad hoc component colors.
- Verify compilation plus rendered desktop and mobile layouts, navigation, menu behavior, links, image loading, and overflow.
