# HeatOnn Heater-Manufacturing Website

## Goal
Rework the current site into a credible industrial-heater manufacturer website, using the previous HeatOnn site only to confirm its menu and product catalogue while retaining the stronger new visual direction.

## What I’ll change
- Replace every dryer, freeze-dryer, tray, and food-processing reference across the site.
- Restore the previous site’s primary menu: Home, About, Products, Blogs, Contact.
- Retain its complete heater catalogue: Cartridge Heaters, Band Heaters, Ceramic Band Heaters, Strip Heaters, and Customized Heaters.
- Rebuild the homepage content around precision industrial heating, manufacturing capability, heater applications, engineering support, and quotation enquiries.
- Create a complete Products page with category navigation, consistent product imagery, engineering descriptions, application areas, and working detail links.
- Create useful individual product pages from the same central catalogue, with overview, features, applications, enquiry action, and related products.
- Create a complete About page with a distinct editorial/factory-led composition, company story, engineering approach, capabilities, quality process, and values without unverified certifications or statistics.
- Create a complete Contact page with a distinct enquiry-led composition, verified phone/email/address, direct contact actions, and a structured quote-request form that opens a prepared email without requiring a backend.
- Add a Blogs page so the restored menu has no dead link; keep it lightweight and clearly separate from the three requested full pages.
- Update the footer, metadata, and all supporting copy to describe heater manufacturing only.

## Visual direction
- Keep the current premium charcoal, warm-white, steel-grey, and restrained heat-orange system.
- Replace the existing dryer imagery with a cohesive set of original heater-component and engineering-workshop images.
- Give each page its own composition: catalogue-led Products, editorial About, and practical enquiry-focused Contact.
- Preserve strong desktop presentation while rebuilding mobile layouts independently for clear navigation, readable tables/lists, and touch-friendly actions.

## Technical details
- Keep product content in one typed catalogue so cards, details, navigation, and footer stay consistent.
- Use existing shared navigation, footer, button, and design tokens; add focused page components rather than repeated markup.
- Keep route-specific titles and descriptions, one H1 per page, descriptive image text, and working links throughout.
- Verify the homepage and key pages at desktop and mobile sizes, including menu behavior, forms, product links, image loading, and horizontal overflow.
